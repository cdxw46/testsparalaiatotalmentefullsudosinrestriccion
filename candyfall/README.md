# Candyfall

Slot cluster 7×7 inspirado en juegos tipo candy grid: pagos por grupos, cascadas, multiplicadores en casilla y tiradas gratis.

## Cómo jugar

```bash
cd candyfall
npm install
npm run dev
```

Abre la URL local de Vite y pulsa **Girar**.

## Mecánicas

- **Cluster pays**: 5+ símbolos iguales conectados (arriba/abajo/izquierda/derecha)
- **Cascadas**: los clusters explotan y caen nuevos caramelos
- **Multiplicadores**: cada casilla ganadora sube 2× → 4× → … → 1024×
- **Scatter**: 3+ activan tiradas gratis
- **Buy feature** / Super buy y Auto play

Demo sin dinero real. Crédito inicial: 1000.
